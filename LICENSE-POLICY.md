# Styio License Policy

**Purpose:** Record the source-license boundary enforced by `styio-audit`.

**Last updated:** 2026-04-24

All Styio-family repositories are Apache-2.0 source projects. The accepted SPDX identifier is `Apache-2.0`.

Any source-derived tool, binary distribution, package, service component, or build artifact that redistributes Styio-family source or binaries must preserve the Apache License, Version 2.0 terms, copyright notices, NOTICE content when present, modification notices, and patent-license conditions required by Apache-2.0. This policy covers `styio`, `styio-spio`, `styio-view`, `styio-platform`, and `styio-audit`.

`styio-audit` enforces this as a repository gate by checking for Apache-2.0 license evidence, matching package metadata, and this source-distribution notice. The policy intentionally removes GPL-style copyleft inheritance from the Styio language and surrounding repositories.
